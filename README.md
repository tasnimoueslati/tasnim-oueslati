## 🚀 Projets

### ☁️ Cloud Security Monitoring Platform

Conception d'une infrastructure Azure sécurisée, provisionnée avec Terraform, comprenant un cluster AKS, Azure Key Vault et des identités managées.

- Gestion des accès selon le principe du moindre privilège avec Kubernetes RBAC.
- Gestion sécurisée des identités avec Workload Identity (OIDC).
- Segmentation réseau avec NSG et Calico NetworkPolicies en refus par défaut.
- Sécurisation des communications HTTPS avec Traefik et cert-manager.
- Centralisation des journaux d'audit dans Azure Log Analytics et analyse avec KQL.
- Supervision et alertes avec Prometheus, Grafana et Alertmanager.

**Technologies :** `Azure` `Terraform` `AKS` `RBAC` `Key Vault` `OIDC` `KQL` `Calico` `TLS`

🔗 [Voir le dépôt GitHub](https://github.com/tasnimoueslati/cloud-security-project.git)

### 🤖 JobPilot AI — Assistant multi-agents de candidatures

Développement d'un assistant intelligent basé sur LangGraph pour automatiser plusieurs étapes du processus de candidature.

- Analyse des offres d'emploi et évaluation de la correspondance entre CV et offre.
- Génération de lettres de motivation et préparation aux entretiens.
- Intégration d'un pipeline RAG avec pgvector pour ancrer les réponses dans les données du profil.
- Automatisation de l'ingestion des offres et des relances via n8n et Telegram.
- Développement d'un tableau de bord Streamlit pour suivre les candidatures.

**Technologies :** `Python` `LangGraph` `RAG` `pgvector` `n8n` `Telegram` `Streamlit`

🔗 [Voir le dépôt GitHub]https://github.com/tasnimoueslati/JobPilot-AI.git)

### 🌱 GreenRoots — Plateforme agricole Cloud Native
